## 复现

在游戏目录启动 `python server.py --port 18081`。在攻略仓库目录执行：

```powershell
$env:NCT_BASE_URL='http://127.0.0.1:18081'
node tests/achievement-filter.cjs E:/nct
node tests/routes-ui.cjs E:/nct
node tests/english-edition.cjs E:/nct
python tests/install-routes.py E:/nct
```

将 `E:/nct` 换成自己的游戏目录。完整记录：[筛选](../tests/achievement-filter-results.json)、[路线界面](../tests/routes-ui-results.json)、[两局通关](../tests/english-edition-results.json)、[安装升级](../tests/install-routes-results.json)。本轮没有重新穷尽105组合或全部随机序列。
