# 成就面板体验调整与测试

日期：2026-10-19。

## 调整

- 后续整局搜索移到Web Worker，主界面先给当前建议；切换目标、作答或关闭成就引导会取消旧任务。
- 默认展开本题的一条建议。其他选项、下次访问、成就条件和计算数据按需展开；进入访问环节会展开访问表。
- 展开的项目在语言切换和后台结果更新时保留。换目标时收起上一目标的条件。
- 面板保留必要的条件提示，将路线出处与详细数据放到折叠区，精简重复提示。

## 实测

原版0db149e在2020拜登／哈里斯、选择406票目标时，同步整局规划耗时约17193毫秒，阻塞主线程。改后实际目标切换处理约15毫秒，后台计算期间页面计时器正常运行，关闭开关可取消搜索。这是本机Chrome的对照样本。

常规攻略初次显示高度从约1042像素缩至291像素；带凯恩成就及设置提示的实际页面约395像素。对比是在1440像素宽度下进行；展开详情后按内容增长。

- 后台规划结果与同步只读算法逐项一致。
- 目标切换、取消搜索、展开选项、语言切换均保持游戏对象及随机调用计数。
- 390／1440像素、80／100／125／150% CSS缩放检查通过。
- 拜登／德明斯406票、肯尼迪／约翰逊困难成就、汉弗莱／康纳利高票、克林顿／凯恩锈带成就，各完成中文和英文一局，共8局实际解锁，数值与随机记录一致；所有外网请求均阻断。
- 新装、从aedd7ed及0db149e升级（含新增Worker）、未知文件及译文冲突检查通过。
- 原7算法、111数据文件、105组合与32770剧本文本完整性检查通过，748双语键签名通过。

证据：[改前测量](../tests/performance-baseline-2026-10-19.json)、[响应与算法对照](../tests/compact-performance-results.json)、[8局通关](../tests/compact-playthrough-results.json)、[控件与布局](../tests/routes-ui-results.json)、[升级安装](../tests/install-routes-results.json)。
