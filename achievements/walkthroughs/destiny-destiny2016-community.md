# Destiny Arrives All the Same

[All achievements](../README.md) · [Live coach](../LIVE_COACH.md)

**Setup:** 2016 — Hillary Clinton / Tim Kaine; Proportional; Impossible (0.9).

**Goal:** Record exactly 232 or 306 of your own electoral votes in each of 1964, 1976, 1988, 2000, 2012, 2016 and 2020, using the same browser save. The entire state map need not match history.
