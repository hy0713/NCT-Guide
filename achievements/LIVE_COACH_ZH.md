# 游戏内实时成就引导

## 使用

安装／升级本仓库后启动游戏，选好年份、总统和副总统。点击顶部“攻略（含剧透）”，在游戏下方的“本局目标”选择成就。默认空目标保留原来的普通胜选建议，目标选择会保存在localStorage。

不想打成就时，取消勾选 **“启用成就引导”**。成就目标和提示会收起，专项规划停止，答案与访问恢复普通胜选排序；总攻略开关保持开启。重新勾选会恢复之前的目标。开关独立保存，只控制引导，不关闭原游戏的成就解锁。

- 列出当前组合可尝试的成就，逐项检查年份、候选人、搭档、难度、模式和特殊资格。
- 必要答案到来时列出完整译文，并置于本题建议首位。指定答题位置也会核对；选错后提示本局已错过条件。
- 针对最低／最高／精确选举人票、普选票、指定州、必须排第二的州等，重新比较当前答案与下一次访问的预测效果。胜选／高票目标另做有限整局规划，假定后续题目和选项来自已载入数据，出现实际分支时重算。故意输选举和控票目标不会再盲目使用普通胜选排序。
- 306／232跨年目标显示已记录年份；已记录的当前年份提示换年。2016a百局目标显示真实累计数。
- 不兼容的目标自动展开替代组合建议，不会擅自重开或改变你的选举。难度／模式不合格、答错了题，分别说明原因，不把它们混称为搭档绝对不可能。
- 最终结果保留面板，按实际成就存档显示解锁或尚未解锁。原作每局成就优先级依然生效。

## 如何推荐搭档

覆盖31个原生成就、105种内置组合。首先根据源码硬条件和答案存在性排除不兼容组合；再按对应目标参考已有种子1776的单局结果。高级模式的结果不冒充普通成就的合规证据；特殊难度没有对照时也不作概率比较。

这些参考来自普通胜选攻略，**不是所有成就的实测成功率**。没有数据时显示“仅确认兼容”，不把列表首项说成数学最优。某个配置下的一次失败也不等于该组合永远无法完成。

## 实际验证与已知限制

当前实现通过的实际结果保存在 `tests/guide-achievements-results.json`：

- 31项目的全部候选推荐均符合静态规则，105组合逐一检查不改写输入。
- 凯恩组合选择桑德斯成就时提示不兼容并推荐桑德斯；桑德斯组合允许继续。
- 2012奥巴马的729、330强制答案会实时排首位，漏选后立即提示不可补救；168也在其题目出现时优先。
- “最多4票”选择低票路线，“恰好269票”按距目标排序；不合格难度和高级模式会明确阻止继续使用目标路线。
- 一局2012奥巴马／拜登依实时建议真实完成25题，确实选择729、330、168，**最后败选，未解锁realdebate**。这说明当前局部贪心建议不能保证该困难成就，不能把答对前置条件当成成功。报告保留真实失败结局，不改难度或数值去伪造成功。
- 一局2016a真实通关解锁why，面板在结果页读取并显示实际解锁。
- 一局2016克林顿／桑德斯按实时规划取得342票并获胜，但未达到351票，thebern未解锁。保留实际未达成结果，不声称指导策略已覆盖该成就的必达解。
- 中英文切换保持完整游戏状态与随机调用计数；390px和80／100／125／150%缩放检查面板边界。

这里是按源码约束、当前预测和有限搜索工作的互动教练，不是穷尽所有随机序列的完整路线求解器。未来选择、条件分支、精确选举人票、指定第二名和高难成就仍可能需要重试、人工判断或更好的整局搜索。当前有限规划不模拟未来访问、条件事件或所有选项出现概率；规划候选答案可能在后续实际分支中不可用，届时按可见选项重算。预测不自动操作，不能确保“按第一项一直点”完成全部成就。

## 开发维护

运行时规则与基线在 `guide/achievement-data.js`，逻辑在 `guide/achievements.js`，文案在 `guide/messages.json`。规则与英文原版成就判定分离；未使用eval执行判定，也不修改原游戏或成就存档。

```powershell
python tools/build-achievement-runtime.py "D:\Games\NCT-Chinese-Version"
python tools/achievement-messages.py
python install.py "D:\Games\NCT-Chinese-Version" --upgrade --dev-tools
# 启动目标游戏服务器后，在游戏目录执行
node tests/guide-achievements.cjs
```

安装器保留已发布旧版本哈希；未知修改先拒绝，且在拒绝时不写入其他文件。运行时安装不覆盖个人开发测试脚本。所有预测仅在副本上计算，不调用游戏的随机源。
