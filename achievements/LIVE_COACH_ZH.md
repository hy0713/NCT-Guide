# 游戏内实时成就引导

## 使用

安装／升级插件，选择年份、总统与搭档，点击顶部“攻略（含剧透）”，在“本局目标”选择成就。目标与独立成就开关保存在localStorage；语言切换、攻略操作不会重开当前选举。

取消勾选 **“启用成就引导”**，即可停止成就专项规划、恢复普通胜选建议。顶部总攻略开关可关闭整个面板。两个开关都不阻止原游戏自然解锁成就。

- 固定路线按组合、模式、难度、问题ID、答案ID、英文指纹匹配，在当前题目显示建议答案，在访问环节显示下一州；不会自动代选。
- 优先使用已有实际解锁记录的路线。原文改变、设置不符、答案或访问偏离路线时会明确提示，停用固定序列并回到条件／模型建议。
- 社区来源未指定某题时显示缺口，按可见选项重新推演，不把缺题伪装成完整作者攻略。
- 组合不符时列出符合源码条件的替代组合，优先已有实际解锁记录的搭档，并显示其模式、难度和测试次数。次数不是胜率。
- 菜单可以选择其他已测试路线，也会标注尚未实际解锁的候选。未测试的批量模型候选不进入运行时菜单。
- 结算后读取真实成就存档。必要回答漏选、难度不合格、高级模式禁用等，分别说明原因。

## 已验证覆盖

[覆盖报告](COVERAGE_ZH.md)记录 **31／31项有实际解锁证据**。本次路线回归及原版操作／累计流程记录613局实际浏览器游戏，保留全部失败；它们不是613次不同的独立随机试验，也不是成功概率。

- 27项普通单局目标均有已解锁路线；其中26项在专门的52局中英文已知成功夹具回归中再次解锁，最后的锈带目标另有中英文各一局实际解锁。
- 殊途同归：七个年份在**同一浏览器存档**实际累计，中文和英文分别完成七局并解锁整项成就；单年份路线统计仅指该年份达标，不冒充整项成就解锁。
- 百局成就：同一隔离存档真实完成100局2016a，每局检查原版计数递增，没有写入或伪造成就计数。胜选不是必要条件。
- 两项BIGSHOT彩蛋使用原版键盘与作弊菜单操作，单独验证；普通成就测试均未启用作弊。

详细原始记录见 [普通逐题回归](../tests/community-route-results.json)、[已知成功双语回归](../tests/verified-route-results.json)、[后续困难目标](../tests/remaining-route-results.json)、[锈带路线改编](../tests/whatbelt-source-results.json)、[锈带微调及真实结果](../tests/whatbelt-neighbor-results.json)、[原版彩蛋与累计成就](../tests/procedural-achievement-results.json)。报告中的passed指脚本与回归断言通过，**不意味着每局都解锁**；每局有独立unlocked字段。

## 最后一项的机制说明

“不赢锈带仍获胜”的已解锁路线为2016克林顿／凯恩、比例分配、Impossible（0.9），前六次访问佛罗里达、后六次访问新罕布什尔；测试夹具18实际取得270票且在密歇根、宾夕法尼亚、威斯康星均排第二。逐题ID保存在`whatbelt-Kaine-FL6-NH6`。

原版比例分配并非最大余数法：各候选人票份额乘州选举人票后向下取整，所有剩余票都给州内第一名。因此即便是比例分配，取得其他州第一名仍会影响能否凑齐270票。先前一条路线虽然取得270票，却以极小优势赢下密歇根而失去成就资格；另一次调整后只得269票。这些失败均保留。

该路线结合能够读取的社区前9题、最后1题和源码模型搜索，中间答案及访问次数经过实际调整；不冒充原作者完整路线。游戏随机结果仍可能使锈带转为本人第一或不足270票。

## 边界

31项都有成功证据，**不等于每局100%取得，也不等于105种搭档都能完成所有成就**。测试使用可重现随机夹具，未穷尽所有随机序列；成功夹具编号不进入发布运行时，也不改变玩家随机流。普通预测保留零噪声假设；偏离固定路线后的模型推演不是成功证明。

原版每局else-if成就优先级保留。若同时满足多项，只授予其中优先项；需要另一局继续。普通成就要求合法模式与难度，Sea to Shining Sea和BIGSHOT不合格；菜单名Hard（0.95）也不满足肯尼迪困难成就的0.9门槛。

浏览器存档按地址和端口隔离。跨年和百局应固定使用同一浏览器、同一地址及端口，不要清理本地存储。

## 维护与重现

路线源数据在`achievements/community-routes.json`；模型候选、来源、映射缺口、实测统计独立保存。运行时由`tools/build-achievement-runtime.py`生成，普通计算器仍来自未修改的原版函数。以下命令在攻略仓库目录执行；升级历史测试需要保留Git历史，普通安装不需要Git。工具需要目标游戏的开发依赖；默认服务器为localhost:18081，可设置NCT_BASE_URL。

```powershell
node tools/validate-community-routes.cjs "D:\Games\NCT-Chinese-Version"
node tools/record-route-evidence.cjs
python tools/build-achievement-runtime.py "D:\Games\NCT-Chinese-Version"
python install.py "D:\Games\NCT-Chinese-Version" --upgrade --dev-tools
node tests/routes-ui.cjs "D:\Games\NCT-Chinese-Version"
python tests/install-routes.py "D:\Games\NCT-Chinese-Version"
```

`tests/community-routes.cjs`支持NCT_ROUTE_IDS、NCT_ROUTE_SEEDS、NCT_ROUTE_REPORT；NCT_ROUTE_REQUIRE_UNLOCK只用于已经成功的夹具回归，不能用它预判新候选成功。完整回归默认可能耗时较长。

安装器只升级已发布文件哈希及已知旧文案，先检查全部冲突再写入；未知个人代码和译文均拒绝覆盖。来源网页仅供核对，游戏内已保存离线数据，不调用在线翻译或攻略接口。
