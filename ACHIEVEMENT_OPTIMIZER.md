# Achievement route improvements

Six updated routes are available in the November 19 live coach and English walkthroughs. Native game results and the actual achievement save determine success.

| Achievement | New setup | Screening, old → new | Separate validation, old → new |
| --- | --- | ---: | ---: |
| Hubert Horatio'd | 1968 Humphrey / Muskie · Default · Normal (0.97) | 0/3 → 3/3 | 1/8 → 8/8 |
| The Vice With No Vice | 1960 Nixon / Goldwater · Proportional · Normal (0.97) | 2/3 → 3/3 | 4/8 → 8/8 |
| Death Swap | 2000 Gore / Graham · Default · Normal (0.97) | 1/3 → 3/3 | 1/8 → 7/8 |
| The Dark Brandon Rises | 2020 Biden / Demings · Default · Normal (0.97) | 1/3 → 1/3 | 2/8 → 3/8 |
| MAGA... Again | 2020 Trump / Haley · Default · Normal (0.97) | 0/3 → 1/3 | 0/8 → 1/8 |
| Not Because It Is Hard, But Because It Is Easy | 1960 Kennedy / Humphrey · Default · Cakewalk (1.33) | New route 3/3 | New route 8/8 |

The first three sequences screened candidates; the next eight were held back for validation. A promoted route matched or beat the old screening count, improved the separate validation count, and unlocked at least twice overall. The previous Cakewalk route used `AA`, a row with no clickable map area. Its replacement visits Alabama five times and Oklahoma seven times. It unlocked on all eleven sequences using the real map hit areas.

The live coach now checks usable routes against completed answers and visits. After a deviation, it can join another tested route that still fits the run. Death Swap avoids handing the award to I'm My Own Master Now first. For A Rainbow Coalition, the coach flags the answer that would complete the prerequisite answers for Tanks and Taxes.

The comparison contains 258 route/seed rows. Fourteen test-only runs used a callback for a district with no map hit area and were excluded from route selection. The existing Rust Belt, Impossible Kennedy and Florida routes stayed in place. MAGA reached the exact 322-vote threshold twice and may still require retries. The existing Sanders route unlocked in three extra checks.

All six routes unlocked when followed through the installed coach in both languages, for 12 offline games with matching bilingual results. A separate Nixon run began on the old route, went to California on the first visit, switched to the new route, and unlocked.
